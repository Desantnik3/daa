# КП_База — рабочее пространство для коммерческих предложений

База цен и проекты КП по слаботочным системам.

## Установка на рабочий стол (Windows)

### Шаг 1. Скачать проект

1. Откройте https://github.com/Desantnik3/daa
2. Нажмите **Code** → **Download ZIP**
3. На рабочем столе создайте папку **КП_База**
4. Распакуйте ZIP **внутрь** этой папки

Должно получиться:

```
C:\Users\ВАШ_ИМЯ\Desktop\КП_База\daa\
```

Переименуйте `daa` в содержимое или распакуйте так, чтобы на рабочем столе была папка:

```
Desktop\КП_База\
├── data\
├── projects\
├── templates\
├── scripts\
├── создать_структуру.bat
└── README.md
```

### Шаг 2. Создать подпапки (если их нет)

Дважды щёлкните **создать_структуру.bat** в папке КП_База.

### Шаг 3. Открыть в Cursor

1. **File → Open Folder**
2. Выберите `Desktop\КП_База`
3. Новый чат → режим **Local** (не Cloud Agent)

### Шаг 4. Перенести существующие файлы КП

Положите вручную:

| Файл | Куда |
|------|------|
| Готовые КП заказчиков | `projects\` или `КП_Итоговые\` |
| База цен (когда появится) | `data\prices.xlsx` |

## Структура

| Папка | Назначение |
|-------|------------|
| `data/` | База цен — **только на вашем ПК**, не в Git |
| `projects/` | Файлы КП по объектам — **локально** |
| `templates/mappings/` | Карты шаблонов заказчиков (какая строка → какая цена) |
| `scripts/` | Скрипты подстановки цен в Excel |
| `КП_Итоговые/` | Архив отправленных КП |

## Конфиденциальность

Папки `data/` и `projects/` перечислены в `.gitignore` — при работе с Git они не попадут на GitHub.

**Не загружайте файлы с ценами в публичный репозиторий.**

## Контекст для локального агента

Скопируйте в новый локальный чат:

```
Работаем в папке КП_База на рабочем столе.
Задача: база цен для КП (слаботочные системы).
Типы цен: offered_current, offered_other, won_current, won_other, contractor.
В файлы заказчиков подставляем только цены, структуру не меняем.
Создай prices.xlsx в data/ и структуру листов.
```
